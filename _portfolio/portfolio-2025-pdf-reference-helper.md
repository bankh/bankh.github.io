## Project Overview

PDF Reference Helper is a Chrome extension that extracts references from academic PDFs and provides one-click access to Google Scholar searches, BibTeX export, and a movable persistent window for multitasking.

## Key Features

- Reference extraction for numbered and author-year styles
- One-click links to Google Scholar and PDF (via DOI/arXiv)
- BibTeX export for selected references
- Persistent window for easy cross-referencing
- Local caching; no data is transmitted
