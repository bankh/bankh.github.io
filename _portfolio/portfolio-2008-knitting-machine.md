excerpt: "Undergraduate senior design project (B.Sc. Textile Engineering, Istanbul Technical University) applying mechatronics to a double-jersey circular knitting machine. The work integrated microelectronics, sensors, and software to automate fabric production and built a low-cost Yarn Input Tension (YIT) data acquisition system in LabVIEW capable of monitoring up to eight yarn lines, enabling speed/tension control and the detection of process faults such as broken needles."
